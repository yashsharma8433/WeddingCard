# Mohit weds Mohini — Digital Wedding Invitation Card

A bespoke, royal Indian digital wedding invitation card website created for **Mohit & Mohini**, inspired by the luxury aesthetic of [yumisani.com](https://yumisani.com).

## ✨ Features
- **Sacred Inscription & Opening Reveal**: Rolling countdown timer and auspicious `॥ श्री गणेशाय नमः ॥` animation.
- **Hero Monogram & Talisman**: Handcrafted watercolor floral crest with "M & M" monogram and swinging Evil Eye (*Nazar Na Lage*) talisman.
- **Falling Petals Animation**: Dynamic 2D canvas simulation of falling rose and marigold flower petals.
- **Wedding Itinerary (Programme)**:
  - **Day 01 (25 Nov 2026)**: Haldi Utsav, Mayra (Bhaat), and Sangeet & Sufi Night (Featuring *Gul Sufi Band*).
  - **Day 02 (26 Nov 2026)**: Baaraat Procession, Jaimala (Varmala), Preeti Bhoj (Reception), and Vedic Pheras & Saptapadi (Featuring *Kiran Narula*).
- **Interactive Dress Code Guide**: Curated color palettes (Marigold, Royal Blue, Daylight Pastels, Auspicious Crimson) with outfit recommendations for men and women.
- **Venue & Destination**: Ivara Resorts & Spa, Khajuraho photo gallery, travel routes, and map links.
- **Bilingual Support**: Toggle between English and Hindi (`EN` / `हि`).

## 🚀 Quick Start

Run locally with any static web server:

```bash
# Python 3
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your web browser.

## 🌐 Deployment
This is a static web application that can be deployed instantly to **GitHub Pages**, **Vercel**, or **Netlify**.
